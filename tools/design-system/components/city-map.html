City map

Original SVG, drawn rather than scanned, so it can be clickable and theme-aware. Every colour comes from a token, which is why a palette change reaches all the way into the cartography. The three district regions are links; the walls, gates and labels are not.

light
dark

Token mapping: land light, water lightgray, Upper City fill highlight, Old Wall and gate markers secondary, later city walls darkgray, minor labels gray. The Old Wall is deliberately the only structure in secondary, so it reads as the oldest thing on the map.
Interaction: drag to pan, wheel to zoom, buttons for zoom and reset. A drag that travels more than six units cancels the click, so panning across a district does not navigate.
Build notes: var() must go in a style attribute, not a presentation attribute like fill="var(--x)", which is not reliably supported. Gate marker radii are set with an r attribute rather than the CSS r property, for the same reason.
Palette risk: this is the component most exposed to a palette change. A softer secondary stops reading as a city wall and starts reading as decoration.
