Ascent from Avernus

Design system for the campaign wiki at extendon64.github.io/avernus

A Dungeons and Dragons campaign wiki, built on Quartz 5, read by players between sessions. The house premise inverts the published adventure: instead of Baldur's Gate being dragged down into Avernus, part of Avernus bleeds up into the city. The visual language follows from that, warm parchment against something hotter pushing through, rather than the cold navy that stock fantasy themes reach for.

This is a mirror, not the source

Do not treat these files as the implementation. They are previews, kept so the system can be seen in one place. Editing them changes nothing on the site.

The real definitions live in two files in the site repository:

FileOwns
quartz.config.yamlThe nine colour tokens for both modes, and the three typefaces. Under configuration.theme.
quartz/styles/custom.scssEvery component: hero, card grid, the three callouts, table and blockquote treatment, and the map.

Rules the system runs on

  • Components read tokens, never literals. That is what lets a palette swap reach the map's Old Wall and the contract callout's border without touching either file.
  • Dark mode inverts the token names, not the roles. light is the page ground in both modes; in dark mode it happens to be near-black.
  • Callout props suppress the admonition icon. Notice, broadsheet and contract are objects in the world, not warnings to the reader.
  • One flourish per component. The broadsheet gets a rotation, the contract gets the only gradient, the hero gets the only diamond. Stacking them reads as noise.

Traps worth remembering

  • Blank lines inside raw HTML blocks in Markdown terminate the block. Everything after gets orphaned into stray paragraphs, and the build still reports success. This silently broke the map once.
  • Quartz slugifies URLs to lowercase, and mixed-case links serve a meta-refresh stub rather than the page.
  • Apostrophes survive slugification. A note called "Map of Baldur's Gate" becomes map-of-baldur's-gate. Name files to avoid it.
  • Plugin themes cost about 740 KB of CSS. Native palette changes cost nothing, which is why the palette candidates are built into the config rather than adopted as themes.
