Cinzel has no lowercase worth the name at small sizes and no italic, so it never runs as body copy or inline emphasis. If a heading needs to be long, let it wrap: headings carry text-wrap: balance. Where the face is unavailable the stack falls back to Georgia, which keeps the serif texture but loses the inscriptional feel.
